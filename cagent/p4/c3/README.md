# C3 — partial

`ProofPursuit.P4.Progress.solution` proves `Statement k` for every `2 ≤ k ≤ 6`. It combines the `k = 2` base case with the complete C1 (`k = 3`), C2 (`k = 4`), `Five` (`k = 5`), and `Six` (`k = 6`) proofs.

The cases `k = 7` and `k = 8` remain unproved in this package, so C3 is **partial**. Source: [`../lean/ProofPursuit/P4/Progress.lean`](../lean/ProofPursuit/P4/Progress.lean). Build and check it using the commands in the [P4 README](../README.md).
