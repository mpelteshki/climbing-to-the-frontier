# C3: d + 1 lines

Only d = 1 and d = 2 are covered. For d = 1, `Angles.c2_m2` proves the two line representatives have angle zero. For d = 2, `Angles.c3_d2` proves the three planar line angles sum to at most π. These results are in [Angles.lean](../Angles.lean); run `lake env lean Angles.lean` from the package root. No general d proof is claimed.
