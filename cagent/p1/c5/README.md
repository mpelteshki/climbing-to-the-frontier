# C5: d + 2 lines

Only d = 2 is covered. `Angles.c5_d2` in [Angles.lean](../Angles.lean) proves the six angles formed by four planar lines sum to at most 2π. Inputs are arbitrary unit Cartesian representatives, with repeated lines allowed. Run `lake env lean Angles.lean` from the package root. No general d proof is claimed.
