# P2 — Uphill paths on the hypercube
Source audited in authenticated browser: https://hackathon.bainsa.ai/p/p2, 2026-09-26. The page states that C1–C4 require values plus explicit full binary vertex lists in increasing label order and that these cells are marked correct on the values alone.
A labelling is a permutation of all d-bit vertices. A valley has no lower-labelled neighbour. Uphill paths start at a valley, follow edges with strictly increasing labels, and include singleton valleys. U(Q_d) minimizes their count over all permutations.
