# Q5 lower-bound evidence and Lean boundary

The primary-author [Bau–Beineke survey, §2, p. 288](https://ajc.maths.uq.edu.au/pdf/25/ajc-v25-p285.pdf#page=4) records `∇(Q5)=14` and the face-doubling lower bound. It cites Beineke and Vandell, [*Decycling graphs*](https://onlinelibrary.wiley.com/doi/10.1002/(SICI)1097-0118(199705)25:1%3C59::AID-JGT4%3E3.0.CO;2-H), *Journal of Graph Theory* 25 (1997), 59–77. The publisher page available here contains the abstract but not the original proof. [Zou's thesis, §2.2.3](https://www.math.mun.ca/~dapike/publications/Theses/YuboZou_PhD.pdf#page=28) and [Hertz's 2021 Table 4](https://jgaa-v5.cs.brown.edu/index.php/jgaa/article/download/paper567/2402/2209#page=17) also record the value without reconstructing its special Q5 proof. Neither citation is a Lean axiom.

For a deletion set `B` of at most 13 vertices, the edge-count identity gives a small finite obstruction. `Q5` has 32 vertices and 80 edges. If `Q5 \ B` is a forest and `|B|=13`, it has at most 18 edges. The surviving edge count is `80−5·13+e(B)=15+e(B)`, so `e(B)≤3`. If `|B|≤12`, the same count already exceeds the forest edge limit even when `e(B)=0`. Thus only the 13-vertex, at-most-three-internal-edges case needs a finite certificate. Every 4- or 6-cycle must meet `B`.

[Decycling5.lean](../shared/Decycling5.lean) lists 80 squares, 640 six-cycles, and 80 edges of `Q5`. Lean verifies each listed cycle is simple and valid, and each edge is distinct and valid. It also proves `no_thirteen_of_search`: **if** the Boolean branch search returns `true`, no 13-or-smaller vertex list with at most three internal edges can hit every listed cycle. The proof uses only standard axioms (`propext`, `Classical.choice`, `Quot.sound`). This is a soundness theorem, not a proof that the root search succeeds.

The standalone, standard-library-only [decycling5_replay.py](decycling5_replay.py) regenerates and validates the edge/cycle inventory, then exhausts the finite obstruction. Run `python3 c2/decycling5_replay.py` from the package directory. For a selected deletion set `S`, an internal-edge count above three can only increase when vertices are added. Otherwise, the first cycle disjoint from `S` must contain at least one vertex of any successful extension; the search branches on every such vertex. At 13 selected vertices an unhit cycle closes the branch. Memoization uses the selected bitset as the complete state, so it does not discard a distinct budget. This is an exact bounded search with no sampling or solver dependency. Its [replay log](decycling5_replay.log) records 42,324 distinct states, 61,072 branches, `UNSAT`, and a 0.265-second run. Source SHA-256: `1fdf6619b2649359217ae6bc13cb62d3593ab229f74e71916e7b04053b4097fe`; inventory SHA-256: `b4b6bdf1fe9c302d2e1baafa9d44c1bef3707cf852446019a85684816abf168b`.

These runtime results are independently replayable evidence, but they are **not** kernel certificates. A monolithic Lean `by decide` on the root search exceeded the practical replay budget and was stopped. The current Lean theorem checks soundness of a list-based search with the same branching rule, but assumes its root Boolean result as a premise; equivalence to the Python bitset program is not formalized.

An independent [decycling5_parity_replay.py](decycling5_parity_replay.py) uses the cube's Hamming-weight parity split and checks forest complements with union-find, without using the 720-cycle inventory. Run `python3 c2/decycling5_parity_replay.py` from the package directory. It examined 12,800 candidate deletion sets with at most three internal edges and found zero forest complements in about 0.26 seconds. Its [replay log](decycling5_parity_replay.log) records source SHA-256 `7b9354149eec8db1083ad07270f7142b80ceb7be5c51d272775bb30b4121de1c` and candidate-stream SHA-256 `9396db7962de031f30f22753ef2eeb1bdbc628be87b3dfdabdc84711f60d01f0`. This cross-check has a different graph test and search partition from the cycle-hitting replay.

The parity replay also isolates the finite gap: for minority-side size `k=3,…,6`, minimizing internal edges over the other side gives `4,4,5,5`, so `e(B)≤3` confines the minority side to at most two vertices. Turning that whole enumeration into a kernel theorem would require chunked checks and a set/edge-count bridge; the replay is deliberately labelled computational evidence.

The [Lean bridge](../shared/DecyclingBridge.lean) proves `P(Q5)≥32+4|B|`, where `B={v:p(v)>1}`, and proves that B meets the listed cycles. It also proves the conditional `pathCount_lower5_of_search_and_edges`, concluding `P(Q5)≥88` given two unproved Lean premises: `Decycling5.search 13 [] = true` and `Decycling5.internalEdges B ≤ edgeCount 5 B`. The Python replays establish the finite Q5 lower result independently, but they do not discharge those Lean premises. C2 meets the task's value-and-label-list criteria; full Lean universal optimality remains incomplete.
